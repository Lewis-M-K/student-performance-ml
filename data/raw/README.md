# Dataset setup

Download the Student Performance dataset from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/320/student+performance), extract the archive, and place `student-mat.csv` in this folder.

The CSV is ignored by Git in this project. Dataset citation:

Cortez, P. (2008). *Student Performance* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5TG7T
